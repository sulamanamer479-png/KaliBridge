# Kali Bridge — مشروع أندرويد أولي

## الميزات الحالية
- واجهة عربية بسيطة.
- زر لفتح Termux إذا كان مثبتاً.
- اختيار ملفات من الهاتف، بما فيها Kali Linux ISO وملفات IPA، وعرض اسم الملف.
- سير عمل GitHub Actions لتجميع APK Debug تلقائياً عند رفع المشروع إلى مستودع GitHub.

## حدود مهمة
- هذا المشروع لا يضمّن Termux أو نظام Kali Linux داخل APK؛ زر Termux يفتح التطبيق الخارجي إذا كان مثبتاً.
- ملفات ISO لا تعمل بمجرد اختيارها. تشغيل Kali يحتاج بيئة مناسبة وإعداداً متوافقاً مع الجهاز.
- ملفات iOS بصيغة IPA لا تعمل كتطبيقات iPhone على أندرويد؛ يمكن اختيارها فقط.
- لا تستخدم أدوات Kali إلا على أنظمة تملكها أو لديك إذن صريح لاختبارها.

## بناء APK من الهاتف فقط عبر GitHub
1. فك ضغط الملف ZIP على الهاتف.
2. أنشئ مستودعاً جديداً على GitHub.
3. ارفع محتويات المجلد كلها إلى المستودع، بما فيها مجلد `.github/workflows`.
4. افتح تبويب Actions في المستودع واسمح بتشغيل Actions إذا طُلب منك.
5. شغّل `Build Kali Bridge APK` من قائمة Workflows أو انتظر اكتمال البناء بعد رفع الملفات.
6. افتح نتيجة التشغيل الناجح، ثم نزّل Artifact باسم `KaliBridge-debug-apk`.
7. فك ضغط ملف Artifact للحصول على `app-debug.apk`.

ملاحظة: قد تحتاج إلى إصلاح أي أخطاء بناء تظهر في سجل GitHub Actions؛ وجود ملفات المصدر لا يعني أن APK قد تم بناؤه مسبقاً.
